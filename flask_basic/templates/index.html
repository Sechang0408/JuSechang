Our Business

OTT 리텐션 분석과 도메인 특화 AI 챗봇

본 서비스는 단순한 예측 화면이 아니라, 사용자 이탈 위험 예측부터 프로젝트 코드 설명 챗봇까지 하나의 웹 서비스 흐름으로 구성되어 있습니다.

01

Churn Risk Prediction

사용자의 이용 빈도, 시청 시간, 요금제, 콘텐츠 다양성 등을 기반으로 안전 / 주의 / 위험 3단계 이탈 위험군을 예측합니다.

02

Training Result

Base Model과 QLoRA 학습 후 모델의 답변 차이를 비교하여 도메인 특화 학습이 어떤 효과를 만드는지 보여줍니다.

03

AI Code Assistant

QLoRA로 학습된 AI 챗봇이 app.py, sc1.html, /predict, risk_model.pkl 등 실제 프로젝트 구조를 반영해 답변합니다.

Service Flow

예측 기능과 AI 챗봇의 서비스 흐름

기능 1에서는 CatBoost 모델로 이탈 위험군을 예측하고, AI 챗봇에서는 QLoRA로 학습된 모델이 프로젝트 코드 구조와 오류 해결 방법을 설명합니다.

1

사용자 조건 입력

성별, 연령, 요금제, 이용 빈도, 시청 시간 등의 값을 선택합니다.

2

이탈 위험 예측

입력값은 JSON 형태로 Flask의 /predict API에 전달됩니다.

3

학습 전후 비교

Base Model과 QLoRA Tuned Model의 답변 차이를 비교합니다.

4

AI 챗봇 사용

실제 챗봇 페이지에서 프로젝트 코드 관련 질문을 입력하고 답변을 확인합니다.
